# HermesGraph 使用指南

HermesGraph 当前以本地单用户 Agent 工作台运行。聊天、会话历史、长期记忆、知识库、知识图谱、
任务和学习记录都从同一个界面访问。

## 1. 启动

在项目根目录运行：

```bash
./scripts/docker_up.sh
```

等待 App 和 Hermes 变为 healthy，然后打开：

- 工作台：`http://127.0.0.1:8001/`
- API 文档：`http://127.0.0.1:8001/docs`

## 2. 对话与上下文

首次打开工作台时，可以填写称呼、当前角色/关注方向、回答语气和兴趣。保存后写入现有 Persona，
后续 Agent 回合会通过有界个人上下文使用这些信息。引导可以暂时跳过，也可以稍后在“个人档案”
中继续设置；跳过不会阻塞聊天。

1. 在“Agent 对话”输入问题，按 Enter 发送，Shift+Enter 换行。
2. 顶部领域选择器用于切换通用、研究和技术文档上下文。
3. 当前会话会自动保存。刷新页面后，前端会从后端运行记录恢复完整问答。
4. 使用顶部会话菜单切换历史对话。菜单同时显示更新时间和轮数。
5. 按 Ctrl+K 或 Cmd+K 打开命令面板。输入标题或最近消息内容可搜索历史对话，选择结果后会从
   服务端恢复该 session，而不是只切换一份本地副本。
6. 点击“新建对话”会生成新的 session，旧会话内容不会进入新会话上下文。
7. 未发送的草稿按 session 保存在本机浏览器中，切换回来后继续编辑。
8. 点击会话右侧的“管理对话”按钮可以重命名或归档当前会话；归档列表中的恢复按钮会重新显示
   会话，历史消息和上下文不会被删除。

同一 session 的最近 8 轮、最多 12,000 字符会作为有界历史提供给会话模型。tenant、project、
user 和 session 任一不同都不会共享历史。

### 2.1 查看当前上下文

点击对话工具栏右侧的脑形“上下文”按钮，可以随时检查：

- 当前对话已经有多少轮，以及回答最多参考多少轮已完成历史。
- 当前用户有多少条有效长期记忆。记忆不会全部无条件塞进 Prompt，Agent 会按当前问题筛选相关项。
- 当前可使用的团队、个人和公共参考知识范围。
- 最近更新的三条长期记忆，并可直接进入统一记忆库管理、纠错或撤回。

上下文面板中的“新建对话”会创建新的 session，因此旧对话历史不会进入新会话；长期记忆仍可按
当前问题召回。刷新页面后，已经保存为长期记忆的消息仍显示“已记住”，点击“查看”进入记忆库。

回答下方只有在 Agent 明确声明某条记忆实际影响了本轮答案时，才会显示“本轮使用 N 条记忆”。点击
可查看记忆摘要并进入统一记忆管理；“当前上下文”里的有效记忆数量仅表示可召回范围，不等于本轮
一定使用。后来撤回的记忆仍会在历史回答中标记“现已撤回”，用于如实保留当时的回答依据。

### 2.2 快速记录任务、日程和笔记

聊天输入框左侧的“快速记录”按钮可以在不发起模型调用的情况下直接保存个人事务：

- **任务**：填写标题、补充说明和优先级，保存到行动中心。
- **日程**：填写标题、日期和时间，保存为带 `due_at` 和 `scheduled` 标签的 Personal Task；当前
  没有另建一套 Event 数据，任务状态、提醒扩展和日归档仍使用同一事实来源。
- **笔记**：填写标题和正文，保存为所选日期的 daily Note。

保存成功后点击“查看”，任务或日程会打开行动中心并定位到刚创建的记录，笔记会打开对应日期的
日历回顾。日历日期格会显示当天到期任务数；选中日期后可以直接查看和完成当天安排，也可以继续
添加当天笔记。生成日归档时，当天 daily Note 会进入摘要和 highlights。

### 2.3 到期提醒

顶部栏铃铛汇总当前用户的逾期、即将到期和今天到期任务。未读数量显示在角标中；打开面板后可以：

- 点击提醒标题或箭头，直接打开行动中心并定位到任务。
- 点击对勾标为已读，或使用顶部按钮全部标为已读。
- 点击时钟，将该任务延后 1 小时再提醒。
- 在浏览器支持时手动开启桌面提醒；系统不会自动请求通知权限。

提醒完全来自 Personal Task 的 `due_at`。任务改期或进入新的提醒阶段会重新变为未读；任务完成、
归档或仍在稍后提醒时间内时不会显示。当前桌面通知要求工作台保持打开，不包含应用关闭后的独立
后台推送。

## 3. 长期记忆

- 点击用户消息或 Agent 回答旁的书签按钮，可以显式写入长期记忆。
- 显式记忆标记为 `user_asserted`，置信度为 1，并按内容幂等去重。
- 在“记忆库”可以查看来源、置信度和更新时间，也可以撤回记忆。
- 回答中的“本轮使用”只统计当前 run 的胶囊或 `recall_project_memory` 返回、且由 Agent 在最终
  回答合同中声明实际使用的记忆；系统拒绝不属于本 run 或当前作用域的记忆 ID。
- 使用记忆库顶部输入框执行“忘记关于 X 的记忆”或“把 X 更正为 Y”。存在多条匹配时，界面会
  要求选择具体记录。
- 普通寒暄不会自动写入 HermesGraph 长期记忆。进入 Hermes Agent 的任务仍会触发隔离的原生
  Memory/Skill review。

## 4. 知识与文件

空对话中的“上传资料”、输入框左侧回形针和文件拖放都在当前聊天页完成，不需要先跳到知识页。
一次可加入最多 5 个 PDF、Markdown、TXT、JSON、CSV、HTML、PNG、JPEG 或 WebP。

- 附件会依次显示“上传中”“解析中”“可提问”或“失败”。处理中会说明完成后才能随问题发送。
- 全部附件就绪后会明确显示“资料已就绪”。可以输入具体问题，也可以不输入文字直接发送，让 Agent
  阅读并总结附件。
- 单个附件失败时，文件旁提供原位重试和移除；下方提示可以进入知识页查看持久入库任务。失败附件
  不会被误标为可提问，也不会阻止用户移除后继续普通聊天。
- 附件同时进入知识库，后续会话可以继续检索，历史消息会保留附件标签。

没有企业资料时可以选择“载入示例工作区”。确认后页面持续显示导入进度；成功后“立即提问”会填入
一条可编辑的 Atlas 示例问题并聚焦输入框。系统根据文档标准来源字段中的 `fixture_id` 判断示例是否
已载入：先上传个人资料不会隐藏示例入口，示例已经就绪时也不会继续展示重复导入按钮。

“知识库”提供资料管理、来源筛选、持久任务重试、逻辑归档和“开始提问”入口。回答中的证据按钮会
打开右侧 Evidence Inspector。

## 5. 反馈与失败恢复

- 点赞会记录正反馈。
- 点踩会打开补充说明输入框，可提交具体改进意见。
- 可重试失败提供“重试任务”；鉴权或连接配置错误不会无意义地重复请求，而是提示检查配置。
- 模型限流、冷却、超时和鉴权失败会显示面向用户的错误，不暴露网关内部详情。
- 停止按钮只取消当前运行，不会删除已完成的会话历史；停止后显示明确的“任务已停止”和“重新开始”。
- 运行期间状态栏显示已经过时间；完成后消息底部保留总耗时，并在实际发生时显示工具调用数和
  学习更新数。耗时是交互反馈，不代表模型推理内容。
- Agent 任务在消息内提供可展开的活动时间线。它只显示请求接收、知识检索、图谱查询、网页搜索、
  工作区读取、记忆/任务操作和回答生成等服务端确认事件，不显示工具参数、原始输出或模型思维。
- 工具尚未返回时，状态会依次说明正在判断任务路径、规划知识与工具或等待结果；超过 10 秒会提示
  复杂问题可能需要多轮检索，超过 30 秒会明确任务仍在运行且刷新后可恢复。这里显示的是系统阶段，
  不是模型思维过程。
- “正在显示回答”表示完整回答已经通过服务端发布检查，工作台正在分段呈现；它不宣称底层模型正在
  实时逐 token 输出。
- 连接中断会显示当前恢复次数，并从最后收到的 event cursor 继续。模型繁忙、超时、鉴权失败和服务
  重启中断使用不同的安全中文提示，便于判断是等待、重试还是检查连接配置。
- 运行中刷新页面或短暂断网不会取消任务。工作台会恢复当前 session 的 running run，并从已确认的
  事件 cursor 继续接收；只有点击“停止”才会向服务端提交取消。

## 6. 当前运行边界

- 简单问候走快速确定性通道，不触发知识检索。
- 事实问答、专业知识、文件、图谱和行动请求由 Hermes Agent 按需调用工具。
- 当前 provider 若处于 `429 model_cooldown`，简单问候仍可使用，依赖模型的任务会提示稍后重试。
- 当前是本地单用户模式；公开部署前仍需增加终端用户鉴权和权限绑定。
- 浏览器刷新和连接中断已支持同一进程内续传；如果整个 App 容器或 Python 进程在运行中重启，无法
  恢复原模型调用，旧 running run 会明确变为 `run_interrupted`，并提供重新发送，不会永久显示运行中。
