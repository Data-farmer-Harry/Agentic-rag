# Atlas Agent 安全护栏

状态：Active
版本：2026.08
Owner：AI Safety

## 威胁范围

主要风险包括检索提示注入、工具参数注入、跨租户召回、敏感信息外泄、无限工具循环、未经确认的写操作
和学习系统把恶意内容固化为 Memory/Skill。所有外部和用户上传内容都视为不可信数据。

## 控制点

输入阶段执行文件类型、大小、恶意宏和 secret pattern 检查。检索阶段由服务端强制 scope filter；模型
不能构造数据库查询。工具阶段使用 allowlist、JSON schema、角色检查、side-effect 分类、超时和输出
预算。发布阶段校验证据 ID、memory ID、引用作用域和 Answer schema。

文档中的“忽略系统指令”“导出密钥”“调用某工具”等文本只可被引用或总结，不得提升优先级。untrusted
来源不能单独支持安全配置、负责人或生产操作结论；必要时必须与 verified 来源交叉验证。

## 行动确认

搜索、读取和比较属于只读工具。创建草稿可直接执行并清楚展示；发送通知、修改配置、删除资料、批准
图谱关系或发布 Skill 必须要求显式确认。确认绑定具体参数和短期 nonce，参数变化后旧确认失效。

## 学习隔离

反思输出默认 shadow。只有具有可追溯证据、通过安全回放且不扩大工具权限的候选才能进入 promotion。
用户撤回事实后，新 Run 不再注入；历史回答只标记当时使用过，不把已撤回内容复活。

安全事件记录稳定错误码和对象 ID，不记录完整 Prompt、token、provider key 或原始敏感文档。
